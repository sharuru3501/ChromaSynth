## 操作(M4)
START=画面切替(プレイ → 音色編集 → シーケンサ → プレイ…) / **SELECT+START=シーケンサ再生/停止(どの画面でも)**
SELECT単押し=チャンネル切替(プレイ/編集画面)。シーケンサは再生したまま他画面で音色編集できる。

### プレイ画面
- A=選択chで発音 / 十字キー=音程(←→半音, ↑↓オクターブ)。各chの発音中ノートとMIDI受信バイトを表示

### 音色編集画面
- ↑↓=パラメータ行, ←→=値(範囲内でクランプ), B押しながら十字キー=試聴ノート変更
- CH1: DUTY VOL ENV(bit3=上昇,下位3bit=速さ) SWT/SWD/SWS(スイープ) VIBD/VIBS(ビブラート深さ/速さ)
- CH2: DUTY VOL ENV VIBD VIBS / CH3: WAVE(矩形,ノコギリ,三角,サイン) LVL(100/50/25%) VIBD VIBS / CH4: WDTH(LFSR幅) VOL ENV
- 値の変更は次のノートオンから反映(ビブラートだけは発音中も即時反映)

### シーケンサ画面(ピアノロール)
- 表示: 上段=ルーラー(チャンネル名[反転]・拍番号・ページ番号 `P1`..`P4`)、中央=16ステップ×16半音のグリッド(左2列が鍵盤ラベル、黒鍵は反転)、下段=`PLAY/STOP BPM L(ループ長) カーソル音名 カーソルステップ`
- 音はバー(長さ付き)。カーソルは枠。再生中は**赤い縦線**が再生位置を示し、再生中はビューが再生ヘッドを追ってページが切り替わる(カーソルを動かすと追従を解除)
- 十字キー=カーソル移動。**Bを押しながら十字キー**=4ステップ/1オクターブ移動(端で自動スクロール)
- **A=カーソル位置に1ステップの音を置く**(試聴音が鳴る)。既に同じ音の下なら試聴のみ
- **A押しながら ←→=音の長さ(短く/長く)、↑↓=移調**(カーソルも追従)
- **B(タップ)=カーソル位置の音を削除**
- **SELECT単押し=チャンネル切替**(カーソルがそのチャンネルの最初の音に移動し、表示窓がそこに合う)
- SELECT押しながら ↑↓=BPM±1、←→=ループ長∓16ステップ(16〜64)
- データは `0`=空 / `OFF` / ノート番号。音は次の非空セルまで鳴る(=バーの長さ)。長さを伸ばすとOFFが右へ動き、次の音に触れるとOFFが消えて音が連続する

### 保存(どの画面でも)
- **SELECT+A = 保存**, **SELECT+B = 読込**。結果は画面最下行に `SAVED` / `LOADED` / `NO SAVE DATA` / `SAVE FAILED` と表示(約1.5秒)
- 起動時に保存データがあれば自動で読み込む。無い/壊れている/版が違う場合はデモパターンのまま
- 保存対象: 4ch分の音色(32B) + パターン(64ステップ×4ch=256B) + BPM + ループ長。自動保存はしない。保存形式はv2(M4b以前のv1は無視される)
- `SAVE FAILED` は書き込み後の読み戻し検証に失敗した時(カートにSRAMが無い等)
- 電源断で消えるのは**未保存の編集**だけ

### 共通
- リンクポート(外部クロック)の MIDI: ch1-4 → CH1-4、各チャンネルはモノ。ch5以降は無視
- CH3 の音域は MIDI 36–95。起動時に CH1 で約0.5秒ビープ
