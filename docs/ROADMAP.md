## 操作(M4)
**START+→ / START+← = 次 / 前の画面**(プレイ ⇄ 音色編集 ⇄ シーケンサ ⇄ キーボード、端で止まる。START を押したまま ←/→ を続けて押せば何枚でも移れる)。START 単独は何もしない / **SELECT+START=シーケンサ再生/停止(どの画面でも、キーボード画面でも)**
SELECT単押し=チャンネル切替(プレイ/編集画面)。シーケンサは再生したまま他画面で音色編集できる。

### プレイ画面
- A=選択chで発音 / 十字キー=音程(←→半音, ↑↓オクターブ)。各chの発音中ノートとMIDI受信バイトを表示

### 音色編集画面
- ↑↓=パラメータ行(1 チャンネル最大 16 行 = 2 ページ。8 行目の次で 2 ページ目に移り、右上に `P1`/`P2`。使わない行は飛ばす), ←→=値 ±1、**SELECT+↑↓=値 ±10**(範囲の端で止まる。押し続けるとオートリピート。SELECT は修飾に使ったのでチャンネルは変わらない)、B押しながら十字キー=試聴ノート変更
- 共通: VOL(初期音量) EDIR(エンベロープの向き、1=上昇) EPAC(エンベロープの速さ 0-7、0=なし) LEN(音の長さ、0=鍵盤を離すまで、それ以外は 1/256 秒単位で APU が自動で止める。CH1/2/4 は 1-64、CH3 は 1-255) PAN(0=両方, 1=左, 2=右)
- CH1: DUTY VOL EDIR EPAC LEN PAN VIBD VIBS / 2 ページ目: SWT SWD SWS(スイープ)
- CH2: DUTY VOL EDIR EPAC LEN PAN VIBD VIBS / CH3: WAVE(矩形,ノコギリ,三角,サイン) LVL(100/50/25%) LEN PAN VIBD VIBS / CH4: WDTH(LFSR幅) VOL EDIR EPAC LEN PAN / 2 ページ目: NDIV(ノイズの分周比 0-7)
- MIDI ページ: CH1-4 BEND VELO MODW SYNC / 2 ページ目: VOLL VOLR(全体の音量 左/右 0-7、NR50)
- **3 ページ目(M9b、CH1-3、すべてフレーム単位)**: ARP1 ARP2(アルペジオ: 基音 → +ARP1 → +ARP2 半音を順に。両方 0 で無効。範囲を超える段は飛ばす) ARPS(1 段のフレーム数、0 は 1) SLID(スライド: 前の音が鳴っている間に次の音が来たときだけ滑る。0 = なし、1 速い〜7 遅い。シーケンサーで続けて置いた音符も滑る) / CH1・CH2 のみ: DUT2 DSPD(DUTY と DUT2 を DSPD フレームごとに交互に。0 = なし。**LEN を使っているときは切り替えない**: NRx1 に長さも入っていて、書き直すと長さが最初からになるため)
- 値の変更は次のノートオンから反映(ビブラートと、PAN・全体の音量は即時反映)

### シーケンサ画面(ピアノロール)
- 表示: 上段=ルーラー(チャンネル名[反転タブ]・小節番号と拍の点・ページ番号[反転タブ])、中央=16列×16半音のグリッド(左2列が鍵盤ラベル、黒鍵は反転)、下段=`PLAY/STOP BPM グリッド分割 カーソル音名`
- 時間は **1拍=12ティック**。**小節・拍は固定の目盛り**で、グリッド分割はその中のサブグリッド(1列=分割のティック数)。ページは必ず拍から始まり整数拍を表示するので、分割を変えても小節は動かない(1/16・1/8Tは1小節、1/8・1/4Tは2小節、1/4は4小節、1/16Tは半小節、1/48は1拍。詳細は ROLL_DESIGN.md)
- 音はバー(長さ付き)。カーソルは枠。再生中は**赤い縦線**がティック単位で滑らかに動き、拍頭では拍の線に重なる。ページは再生に追従(カーソルを動かすと追従解除)
- 十字キー(**押しっぱなしでリピート**)=カーソルを1セル/1半音。**Bを押しながら十字キー**=4セル/1オクターブ
- **Bを押しながらA(同時でも可)=グリッド分割を切替**: 1/4 → 1/4T → 1/8 → 1/8T → 1/16(既定) → 1/16T → 1/48 → 1/4…(Tは三連符)
- **A=カーソル位置に、現在の分割1セル分の音を置く**(試聴音が鳴る)。既に同じ音の下なら試聴のみ
- **A押しながら ←→=音の長さを1セル分 短く/長く、↑↓=移調**(カーソルも追従)
- **B(タップ)=カーソル位置の音を削除**
- **SELECT単押し=チャンネル切替**(カーソルがそのチャンネルの最初の音に移動し、表示窓がそこに合う)
- SELECT押しながら ↑↓=BPM±1、←→=ループ長∓1小節(1〜4小節)
- データは `0`=空 / `OFF` / ノート番号(1セル=1ティック)。音は次の非空セルまで鳴る(=バーの長さ)
- **三連符の入力**: `B`押しながら`A`で 1/8T にして、`A`、`→`、`A`、`→`、`A`(各セルは4ティック=1拍の3分の1)

### 保存(どの画面でも)
- **SELECT+A = 保存**, **SELECT+B = 読込**。結果は画面最下行に `SAVED` / `LOADED` / `NO SAVE DATA` / `SAVE FAILED` と表示(約1.5秒)
- 起動時に保存データがあれば自動で読み込む。無い/壊れている/版が違う場合はデモパターンのまま
- **保存スロット(M12)**: プレイ画面で SELECT+←→ = スロット 1〜8。SRAM のバンク 15 だけに書く(LSDj のデータがあるスロットには書かない)。保存済みのスロットへの SELECT+A は、もう一度押すと上書き。詳細は MANUAL.md
- 保存対象: 4ch分の音色(32B) + パターン(4ch×192ティック) + BPM + ループ長(ティック)。自動保存はしない。保存形式は v7(古い版は無視される)
- `SAVE FAILED` は書き込み後の読み戻し検証に失敗した時(カートにSRAMが無い等)
- 電源断で消えるのは**未保存の編集**だけ

### 共通
- リンクポート(外部クロック)の MIDI: ch1-4 → CH1-4、各チャンネルはモノ。ch5以降は無視
- CH3 の音域は MIDI 36–95。起動時に CH1 で約0.5秒ビープ
