## 操作(M4)
START=画面切替(プレイ → 音色編集 → シーケンサ → プレイ…) / **SELECT+START=シーケンサ再生/停止(どの画面でも)**
SELECT単押し=チャンネル切替(プレイ/編集画面)。シーケンサは再生したまま他画面で音色編集できる。

### プレイ画面
- A=選択chで発音 / 十字キー=音程(←→半音, ↑↓オクターブ)。各chの発音中ノートとMIDI受信バイトを表示

### 音色編集画面
- ↑↓=パラメータ行, ←→=値(範囲内でクランプ), B押しながら十字キー=試聴ノート変更
- CH1: DUTY VOL ENV(bit3=上昇,下位3bit=速さ) SWT/SWD/SWS(スイープ) VIBD/VIBS(ビブラート深さ/速さ)
- CH2: DUTY VOL ENV VIBD VIBS / CH3: WAVE(矩形,ノコギリ,三角,サイン) LVL(100/50/25%) VIBD VIBS / CH4: WDTH(LFSR幅) VOL ENV
- 値の変更は次のノートオンから反映(ビブラートだけは発音中も即時反映)

### シーケンサ画面(16ステップ × P1/P2/WV/NS)
- 十字キー=カーソル移動(`[ ]`で囲まれたセル)。再生中は左端の `>` がプレイヘッド
- A=カーソル位置に音を入れる(空/OFFなら直前の音、音があればその音を拾う)。試聴音が鳴る
- A押しながら: ↑↓=±半音, ←→=±オクターブ
- B=空→OFF(ノートオフ)→空、音→空
- SELECT押しながら: ↑↓=BPM±1, ←→=BPM±10
- セル表示: `...`=空(前の音が鳴り続ける) / `OFF`=ノートオフ / `C-4`等=ノート
- 起動時にデモパターン(アルペジオ+ベース+ハイハット, 120BPM)が入っている。電源を切ると編集内容は消える(保存はM5)

### 共通
- リンクポート(外部クロック)の MIDI: ch1-4 → CH1-4、各チャンネルはモノ。ch5以降は無視
- CH3 の音域は MIDI 36–95。起動時に CH1 で約0.5秒ビープ
