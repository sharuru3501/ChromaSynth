# ChromaSynth 操作マニュアル

画面・ボタン操作・音色パラメータ(PATCH 画面の略称)の一覧です。設計の話は [ARCHITECTURE.md](ARCHITECTURE.md)、MIDI の仕様は [MIDI.md](MIDI.md)、状態は [ROADMAP.md](ROADMAP.md)。
ボタン名: 十字キー(↑↓←→)、A、B、START、SELECT。英語版: [MANUAL.en.md](MANUAL.en.md)。用意とつなぎ方: [GETTING_STARTED.ja.md](GETTING_STARTED.ja.md)。

> **注意**: 保存はカートリッジの SRAM に書く(通常版は 4 スロット、機能制限版(SRAM 8 KB)は 1 スロット。1 曲 8 KB、SRAM のバンク 0 から。§1 の保存スロット)。ほかのソフトのデータがあるスロットには書かない(`SLOT IN USE`)。カートリッジの条件は [CARTRIDGES.md](CARTRIDGES.md)。

## はじめの 5 分
1. **プレイ画面**: **A** で、選んだチャンネルが鳴る。十字キーの左右 = 半音、上下 = オクターブ。**SELECT** を単押しで、次のチャンネル(CH1 矩形、CH2 矩形、CH3 波形、CH4 ノイズ)。
2. **START+→** で **PATCH 画面**(音作り)。↑↓ でパラメータ、←→ で値、**A** で試聴。CH1 の DUTY を変えてみる。
3. もう一度 **START+→** で**シーケンサー**(ピアノロール)。十字キーでカーソル、**A** で音符を置く、**B** で消す。**SELECT+START** で再生・停止、**SELECT+↑↓** で BPM。最初からデモのパターンが入っている。
4. 保存: プレイ画面に戻って(START+←)**SELECT+B**。現在のスロットに曲が保存される。**SELECT+A** で読み込み。

## 1. 画面と移動
画面は一直線に並んでいる: **プレイ ⇄ PATCH(音色編集) ⇄ シーケンサー(ピアノロール) ⇄ キーボード**。端で止まる。

| 操作 | 動作 |
|---|---|
| START+→ / START+← | 次 / 前の画面(START を押したまま ←→ を続けて押せば何枚でも移れる)。START だけでは何もしない |
| SELECT を単押し | 次のチャンネル(CH1→CH2→CH3→CH4。PATCH 画面は、その次に MIDI ページ) |
| SELECT+START | シーケンサーの再生 / 停止(どの画面でも) |
| START+↓ | **スロット一覧画面**を開く(プレイ・PATCH・シーケンサーのどこからでも)。START+↑ で元の画面へ戻る |
| START+↑ | **ソング画面**(パターンの並び)を開く(プレイ・PATCH・シーケンサーのどこからでも)。START+↓ で元の画面へ戻る(§4 の後ろ) |
| SELECT+←/→(プレイ画面) | 保存スロットを切り替え(1〜4) |
| SELECT+B | 現在のスロットへ保存(**スロット画面以外の、どの画面でも使える**) |
| SELECT+A | 現在のスロットから読み込み(同じく、スロット画面以外の、どの画面でも) |

**保存スロット**: 音色・パターン 4 つ・パターンの並び・BPM・ループ長をひとまとめ(1 曲)にして、4 か所に保存できる。1 曲が 8KB(バンク 1 つ)。現在のスロットと、そこに保存があるか(`USED` / `FREE`)はプレイ画面の `SLOT n` の行に出る。
- **スロット画面**(START+↓、M24): 4 スロットを縦に並べ、名前と `USED` / `FREE`、選択中の `>` を一度に見られる。**↑↓ でスロットを選び、A でメニューを開く**。メニューは、↑↓ で項目、**A で実行、B で戻る**。この画面では START+←→ は効かない(START+↑ だけで戻る)。
  - **LOAD**: そのスロットの曲を読み込む。**SAVE**: 作業中の曲を、そのスロットへ保存する(使用中なら、確認のあとで上書き)。
  - **NEW**(新規作成): そのスロットに**空の曲**を書き込んで、作業中の曲にする(音色・BPM は初期値、パターンは空、**名前も空**)。使っていないスロットで押すと、そこが曲の入ったスロットになり、読み込みも保存もできるようになる。使っているスロットで押すと、既存の曲が空になる(`AGAIN:ERASE`、もう一度同じ操作で実行)。
  - **COPY TO...**(複製): そのスロットの曲を、別のスロットへコピーする。**行き先は、スロットの一覧から↑↓で選び**(`>` が行き先、`+` がコピー元)、A で実行。行き先が使用中なら、確認(`AGAIN:OVERWRITE`)が出る。スロットが 1 つのカートリッジでは使えない(`ONLY ONE SLOT`)。
  - **RENAME**: そのスロットの曲の名前を変える(8 文字、使える文字は 空白・A-Z・0-9・`-`)。**←→ でカーソル、↑↓ で文字、A で書き込み、B で取り消し**。
  - **DELETE**: そのスロットを空にする(`AGAIN:DELETE`、もう一度同じ操作で実行)。ChromaSynth の曲が入っているスロットだけ。
- すでに保存があるスロットへ SELECT+B(スロット画面ではメニューの SAVE)を押すと、`AGAIN:OVERWRITE` と出る。**約 1.5 秒以内にもう一度**同じ操作をすると上書きする(間違えて消さないため)。
- スロットに LSDj のデータなど、ChromaSynth の保存でないものが入っていたら、書かずに `SLOT IN USE` と出る。
- 結果は画面の最下行に `SAVED n` / `LOADED n` / `NO SAVE DATA n` / `SAVE FAILED n` などと出る(n はスロット番号)。
- 起動時はスロット 1 に保存があれば自動で読み込む(最後に使ったスロットは覚えない)。**自動保存はしない**。

## 2. プレイ画面
- A: 選んだチャンネルを鳴らす(離すと止まる)。
- 十字キー: 鳴らす音の高さ(←→ = 半音、↑↓ = オクターブ)。
- 各チャンネルの発音中のノートと、MIDI で受けたバイトを表示。

## 2b. キーボード画面
プレイ画面と同じ、チャンネルの行と状態の行に加えて、**`BPM nnn   SYNC n`** の行が出る(テンポと、MIDI ページの SYNC の値)。シーケンサー画面に行かなくても、DAW に追従して変わるテンポ(SYNC = 3)が見える。

## 3. PATCH 画面(音色編集)
チャンネルごとの音色を編集する。値の変更は**次のノートオンから**効く(PAN・VIBD/VIBS・全体の音量 VOLL/VOLR は即時)。

### 操作
| 操作 | 動作 |
|---|---|
| ↑ ↓ | パラメータの行を移動(使わない行は飛ばす。8 行ごとにページが変わり、右上に `P1`/`P2`/`P3`) |
| ← → | 値を ±1 |
| SELECT+↑ / SELECT+↓ | 値を ±10(範囲の端で止まる。この間はチャンネルが変わらない) |
| A | 試聴(選んだチャンネルを鳴らす) |
| B を押しながら十字キー | 試聴する音の高さを変える |
| SELECT 単押し | 次のチャンネル |

### パラメータ(略称の意味)
括弧内は値の範囲。**0 のときの意味**を書いてあるものは、0 が「効果なし」。

**全チャンネル共通に近いもの**

| 略称 | 正式名 | 意味 | 対象 |
|---|---|---|---|
| DUTY | デューティ比 | 矩形波の幅(0=12.5% / 1=25% / 2=50% / 3=75%)。音色の硬さが変わる (0-3) | CH1 CH2 |
| WAVE | 波形 | CH3 の波形(0=矩形 / 1=ノコギリ / 2=三角 / 3=サイン、**4〜7 = 自分で作る波形 W1〜W4**)(0-7)。初期値の W1〜W4 は 0〜3 のコピー | CH3 |
| LVL | 出力レベル | CH3 の音量(0=100% / 1=50% / 2=25%)。エンベロープがないので音量はこれだけ (0-2) | CH3 |
| WDTH | LFSR 幅 | ノイズの幅。0=15 ビット(ざらざらした雑音)、1=7 ビット(金属的・ピッチのある音) (0-1) | CH4 |
| VOL | 初期音量 | 音の出だしの音量 (0-15) | CH1 CH2 CH4 |
| EDIR | エンベロープの向き | 0=下がる(減衰)、1=上がる (0-1) | CH1 CH2 CH4 |
| EPAC | エンベロープの速さ | 音量が 1 段変わるまでの時間(1 が速く 7 が遅い)。**0=変化なし**(VOL のまま鳴り続ける) (0-7) | CH1 CH2 CH4 |
| LEN | 音の長さ | **0=鍵盤を離すまで**。それ以外は APU が自動で止める(約 1/256 秒単位)。CH1/2/4 は 1-64、CH3 は 1-255 (0-64 / 0-255) | CH1-4 |
| PAN | パンニング | 0=左右両方、1=左のみ、2=右のみ (0-2) | CH1-4 |
| VIBD | ビブラートの深さ | **0=なし**。大きいほど深く揺れる。MIDI のモジュレーションホイール(CC1)でも上がる (0-7) | CH1-3 |
| VIBS | ビブラートの速さ | 揺れの速さ (0-7) | CH1-3 |

**CH1 だけのスイープ(2 ページ目)**: 音の途中で、ピッチを自動で上下に動かす APU の機能。

| 略称 | 意味 |
|---|---|
| SWT | スイープの間隔(時間)。**0=スイープなし**。大きいほどゆっくり (0-7) |
| SWD | 向き。0=ピッチが下がる、1=上がる(ハードの NR10 の向きに合わせてある。逆に聞こえたら入れ替えて確認する) (0-1) |
| SWS | 1 回の動く量(シフト)。大きいほど 1 回の変化が小さい (0-7) |

**CH4 だけ**

| 略称 | 意味 |
|---|---|
| NDIV | ノイズの分周比。小さいほど高く、大きいほど低い雑音(ハイハット→スネア→バスドラの方向)。WDTH と合わせて音程の高低を決める (0-7) |

### 3 ページ目(CH1-3: アルペジオ・スライド・デューティ切り替え) — M9b
すべてフレーム単位(1 フレーム ≒ 1/60 秒)。

| 略称 | 意味 |
|---|---|
| ARP1, ARP2 | **アルペジオ**。基音 → 基音+ARP1 半音 → 基音+ARP2 半音、の順に繰り返す。**両方 0 で無効**。音域を超える段は飛ばす。長三和音は ARP1=4、ARP2=7、短三和音は 3 と 7 (0-15) |
| ARPS | アルペジオの 1 段のフレーム数(0 は 1 と同じ)。大きいほどゆっくり (0-15) |
| SLID | **スライド(ポルタメント)**。前の音がまだ鳴っているときに次の音が来ると、音程が滑る。**0=なし**、1=速い〜7=遅い。シーケンサーで続けて置いた音符も滑る (0-7) |
| DUT2, DSPD | **デューティの切り替え**(CH1・CH2 のみ)。DUTY と DUT2 を DSPD フレームごとに交互に切り替える。**DSPD=0 で無効**。**LEN を使っている間は切り替わらない**(ハードの NRx1 に長さも入っていて、書き直すと長さが最初からになるため) (DUT2 0-3 / DSPD 0-15) |

### MIDI ページ(SELECT で CH4 の次)
| 略称 | 意味 |
|---|---|
| CH1〜CH4 | その GB チャンネルが聞く MIDI チャンネル(0=無効、1-16)。初期値は 1,2,3,4。同じ番号にすると和音になる |
| BEND | ピッチベンドの幅(半音)。初期値 2 (0-12) |
| VELO | 1=ベロシティで音量を変える、0=変えない |
| MODW | 1=モジュレーションホイール(CC1)でビブラートの深さを変える、0=変えない |
| SYNC | DAW 同期。0=OFF、1=OUT(本体がマスター。音符・クロック・開始/停止を DAW へ)、2=IN(ケーブルのクロックでシーケンサーが動く)、3=FOLLOW(DAW の開始/停止とテンポに追従。プログラムチェンジでパターン、CC で音色) |
| BEAT | **拍子の分子**(1〜16)。`3/4` なら BEAT=3、UNIT=4。0 は 4 として扱う(拍子ができる前に保存した曲) |
| UNIT | **拍子の分母**(4 / 8 / 16 のどれか。画面には分母そのものが出る)。拍の単位(1 拍 = 4 分音符 / 8 分音符 / 16 分音符)を決める |
| VOLL, VOLR | **全体の音量**(左 / 右)。0-7。ハードの NR50 |

### 波形エディタ(CH3 の WAVE = 4〜7) — M9c
- 開き方: PATCH 画面で CH3 を選び、WAVE を選んで **START+A**。戻るのは **START+B**。**WAVE 4〜7(W1〜W4)は編集でき、WAVE 0〜3(プリセット P1〜P4)は見るだけ**(波形を確認して、A で聴ける。変更はできない)。
- 画面: 16 個ずつの波形(カーソルのある前半 / 後半)を棒グラフと 16 進の数字で出す。カーソルの位置の数字は反転。波形は 32 サンプル × 4 ビット(0〜15)。
- 操作: ←→ = サンプルを選ぶ / ↑↓ = 値 ±1(B を押しながらで ±4) / **A = 鳴らす**(押している間。A を押したまま値を変えると、変えるたびに鳴らし直す) / START+A = 次のプリセット(矩形→ノコギリ→三角→サイン)を、いま編集している波形(W1〜W4)にコピー。きれいな三角波やサイン波がほしいときは、これでコピーして、必要なところだけ直す。**LVL は、カーソルのサンプル 1 つの高さ(0〜15)**で、波形全体ではない(波形は 32 個のサンプルの並び)。
- 保存: 4 つの波形は曲と一緒に保存・読み込みされる(古い保存は初期値に戻る)。プリセット(WAVE 0〜3)は今までどおり。
- 波形 RAM は CH3 が止まっているときにしか書けないので、鳴らし直しのとき(ノートオン)に書き換わる。鳴っている最中に値を変えても、次のノートオンから反映。

## 4. シーケンサー画面(ピアノロール)
1 拍 = 12 ティック。画面の見方・設計の詳細は [ROLL_DESIGN.md](ROLL_DESIGN.md)。

| 操作 | 動作 |
|---|---|
| 十字キー | カーソルを 1 セル / 1 半音(押しっぱなしでリピート) |
| B を押しながら ← → | **1 小節ずつ**動く(→ = 次の小節線へ、← = いまの小節の頭へ、頭にいるときは 1 つ前の小節線へ)。B を押しながら押しても、音は消えない(B の短押しの「削除」は、B を離したとき、ほかの操作に使っていなかった場合だけ) |
| B を押しながら ↑ ↓ | 1 オクターブ動く |
| A | カーソルの位置に 1 セル分の音を置く(同時に試聴) |
| A を押しながら ← → | その音を 1 セル短く / 長く。**カーソルは音の最後のセルへ付いていく**(ページの端を超えて伸ばすと、ページがめくれる)。音は 192 ティックの区切り(4/4 の 4 小節め)をまたいで伸ばせる |
| A を押しながら ↑ ↓ | その音を移調 |
| B(タップ) | カーソルの位置の音を削除 |
| B+A(同時でも可) | グリッド分割を切り替え(1/4 → 1/4T → 1/8 → 1/8T → 1/16 → 1/16T → 1/48 → …。T は三連符) |
| SELECT を押しながら ↑ ↓ | BPM ±1 |
| SELECT を押しながら ← → | ループの長さ ∓1 小節(そのパターンの最大まで) |
| START を押しながら A / B | **いま選んでいるチャンネルの、カーソルのステップのパターンを 次 / 前 に切り替え**(P1〜P9、PA〜PG = 10〜16。ソング画面の同じ場所の A / B と同じ。LOOP モードで再生中は小節の頭で入れ替わる。START 中は音を置かない・消さない) |

**ページ(1 画面)**: グリッドの区切りが小節に割り切れるときは、**1 ページ = 小節の整数個**で、小節の途中や次の小節の頭は出ない。4/4 の 1/16 は 1 小節(16 列)、3/4 の 1/16 は 1 小節(12 列。右の 4 列は空き)、3/4 の 1/4 は 5 小節(15 列)、など。1 小節が 16 セルより多いとき(4/4 の 1/16T、1/48 など)は、小節の頭から 16 セルずつ出し、最後の 1 枚は小節の終わりで終わるようにずらす。小節に割り切れない区切り(3/4 の 1/4T など)は、16 セルずつの固定ページ。
| (表示) | **左上の反転タブ**は、チャンネル(`1P` など)。**右上の反転タブ `P1`〜`P4` は、いま編集しているパターン**(ソング画面の `EDIT` と同じ)。**状態行の右端 `L2` は、ループの長さ(小節)**。ルーラーの小節番号(`1`〜`8`)は、そのページの小節線の上に、ループの外でも出る(拍の目盛りは、ループの中だけ) |
| (縦のスクロール) | カーソルが表示の上端・下端を超えると、画面が 1 音程ずつ、押している間じっと追いかけてスクロールする。B+↑↓(1 オクターブ)や、ページが変わるときは、新しい画面を裏で作って、できあがったら一度に切り替える |
| (自動で延びるループ) | ループの終わりより後ろの小節に A で音符を置くと、ループがその小節まで自動で延びる(最大 8 小節。`L2` → `L5` など)。音符を置いたのに鳴らないことはない |
| (カーソル) | 4 小節ごとの区切りをまたいで、パターンの 8 小節ぶん全部を動ける。4 小節の区切りをまたぐ音は、区切りの手前までしか、伸ばす・縮める編集ができない(鳴らすときは区切りをまたいで続く) |
| SELECT 単押し | チャンネル切り替え |
| SELECT+START | 再生 / 停止 |

シーケンサーは再生したまま、他の画面で音色を編集できる。三連符の入れ方: B+A で 1/8T にして、A → → A → → A(1 セルが 4 ティック)。

## 5. キーボード画面(MIDI 受信用)
Chromatic の内蔵 ESP32(BLE / USB)から、DAW の MIDI を受ける画面。この画面では本体のボタンを無視する(誤って鳴らさないため)。
- 抜けるには **START+←**(シーケンサーへ戻る)。
- SELECT 単押し = 次のチャンネル、SELECT+START = シーケンサーの再生 / 停止。
- 接続の手順は [BLE_MIDI.md](BLE_MIDI.md) の「現状」を読む。本体の MENU の System タブで MIDI MODE(OFF / BLE / USB)を選ぶ。

## 6. ソング画面(複数のパターンをつなぐ)
### 考え方(パターンとチェーンの関係)
- **パターン(16 個。P1〜P9、PA〜PG)**: 音符を打ち込む「入れ物」。1 つのパターンに、4 チャンネルぶんの音符が入る。長さは最大 8 小節(ループ長で 1〜8 小節)。
- **チェーン(`STEP`)**: パターンを**鳴らす順番**を並べた表。**4 チャンネル(C1〜C4) × 32 ステップ**で、マス 1 つに「どのパターンを鳴らすか」の番号が入る。チャンネルごとに、別のパターンを選べる(C2 の行の `1` は、パターン 1 の **CH2 の部分**。CH1 の部分ではない)。1 画面に 8 ステップで、4 ページ(`PAGE n/4`)。見出しの数字 1〜8 は、ページの中の位置。
  - `-` は「このステップは、そのチャンネルが鳴らない」。**4 チャンネルすべてが `-` の最初のステップで、曲が終わる**(先頭に戻って繰り返す)。最初のステップは、すべてを `-` にはできない。
  - **ステップの長さ = そのステップの 4 つのパターンのうち一番長いもの**。短いパターンは、ステップの中で繰り返す。拍子は、そのステップで最初にパターンがあるチャンネルのパターンのもの。
- **シーケンサー画面(ピアノロール)は、ソング画面のカーソルの場所(ステップ × チャンネル)のパターンを開く**。ソング画面でカーソルを動かすか、シーケンサー画面で SELECT 単押し(チャンネルを替える)をすると、その場所のパターンが開く。**空(`-`)の場所**を開くと、どこにも使われていないパターンの番号が候補として開く。**最初の音符を置いたときにだけ**、その番号がチェーンに入る(見るだけでは、曲は変わらない)。
- 同じ番号を複数のステップで使っていると、片方を編集すれば、もう片方も変わる(同じパターンを指しているため)。
- メモリは、**共有の枠**(下の「パターンのメモリ」)の範囲でしか使えない。

### パターンのメモリ(M19)
- 箱は、**中身のあるチャンネルの 4 小節ぶん(ページ)だけ**、共有のメモリから借ります。音符のないチャンネルや、使わない小節は、メモリを取りません(ほかの箱が使えます)。
- ソング画面の `MEM nn%` が、使用率です(保存の 8 KB の枠に対する、圧縮後の大きさ)。**100% に近づくと、音符を置く・長くする操作が、`MEM FULL` と出て断られます**(データは変わりません)。だから、作ったものは、いつも保存できます。
- 保存は、借りているページだけを、圧縮して書きます。空のセルが多いほど小さくなり、読み込むと元どおりに戻ります。
- 音符を消して、ページが空になると、メモリに戻ります。

| 操作(ソング画面) | 動作 |
|---|---|
| START+↑ / START+↓ | 開く / 元の画面へ戻る(この画面では START+←→ は効かない) |
| ← → | ステップを動かす(`>` の印。ページがつられて変わる) |
| ↑ ↓ | チャンネルを動かす(C1〜C4) |
| A / B | **そのチャンネルのそのステップだけ**のパターンを +1 / −1(1 → … → 16 → `-` → 1 …)。押しっぱなしで繰り返す。最初のステップは、ほかのチャンネルに 1 つもパターンがないと `-` にできない |
| SELECT+↑/↓ | **ループ / ソング**の切り替え(MODE の行) |

- 再生中は、PLAY の行の右に `PAGEn STEPn`(鳴っているステップ)、見出しの行に、そのステップの数字の左へ小さな三角が出る(ソングモードのみ)。
- **MODE = LOOP**: カーソルのセルのパターン(編集中のパターン)を、4 チャンネルそろって繰り返す。
- **MODE = SONG**: SELECT+START で再生すると、チェーンの先頭から順につなぐ。再生中でも、別のパターンを編集できる(鳴っているパターンは変わらない)。
- **再生中にパターンを選ぶ**: LOOP モードで再生しているときに、A / B で「EDIT」のパターンを変える(またはカーソルを動かす)と、**次の小節の頭**で、そのパターンに切り替わる(それまでは、今のパターンが鳴り続ける。切り替わるとき、鳴っていた音は止まる)。`PLAY P1` の行に、鳴っているパターンと、次に切り替わるパターン(`NEXT P2`)が出る。小節の頭は、拍子(§7)の小節の長さで決まる。切り替わる前に、鳴っているパターンに戻せば、切り替えは取り消され、何度か選び直したときは、最後の選択が使われる。再生していないときは、すぐに切り替わる。
- 保存は、4 つのパターンとチェーンをまとめて(1 曲として)スロットへ書く。
- 8KB の曲を保存・読み込みするので、保存中は 0.3 秒ほど画面と音が止まる(再生中に保存すると、音が一瞬途切れる)。

## 7. 拍子(4/4、3/4、6/8、7/8 など)
- **拍子と小節数は、パターンごと**: パターン 1 は 4/4、パターン 2 は 3/4、のようにできる。編集中のパターンの BEAT / UNIT と、SELECT+←→ のループの小節数が、そのパターンの値になる(パターンを切り替えると、そのパターンの値に変わる)。再生中にパターンを切り替えると、**小節の頭**で入れ替わり、新しいパターンは**同じ小節番号**から、そのパターン自身の小節の長さで続く(そこがループの外なら頭から)。曲モードでも、パターンごとの拍子で鳴る。
- **1 つのパターンの途中で拍子を変える**(1 小節目は 4/4、2 小節目は 3/4)ことは、まだできない。拍子を変えたいときは、パターンを分ける。
- **設定の場所**: PATCH 画面の最後のページ(SELECT でチャンネルを CH4 の次まで進めた MIDI ページ)の、**BEAT(分子)と UNIT(分母)**。↑ を押すと、ページの最後の行(UNIT)に行ける。曲と一緒に保存される(古い保存は 4/4 として読む)。
- **決まるもの**: 1 拍の長さ(分母 4 → 12 ティック、8 → 6、16 → 3)、1 小節の長さ(分子 × 1 拍)。ルーラーの小節線と小節番号、拍の目盛りは、この長さで出る。ループの長さ(小節)は、パターンの 384 ティックに入る数まで(最大 8 小節。`5/4` は 6 小節)。
- **音符のデータは、そのまま**: 音符は「何ティック目」に置かれているので、拍子を変えても、音符は動かない。小節線の位置と、ループの終わりだけが変わる。作った曲の拍子を、あとから変えても、壊れない。
- **BPM** は、いつも 4 分音符の速さ(`6/8` でも、4 分音符が 1 拍分の目安になる)。
- 使えない拍子: 分母が 2(2/2、3/2)と 32 以上。分子は 16 まで。
- 拍子を変えると、シーケンサー画面のルーラーが、その場で引き直される。ループが新しい最大の小節数より長いときは、再生・表示の上で、384 ティックで切られる。
