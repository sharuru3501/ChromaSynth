# ChromaSynth 操作マニュアル

画面・ボタン操作・音色パラメータ(PATCH 画面の略称)の一覧です。設計の話は [ARCHITECTURE.md](ARCHITECTURE.md)、MIDI の仕様は [MIDI.md](MIDI.md)、状態は [ROADMAP.md](ROADMAP.md)。
ボタン名: 十字キー(↑↓←→)、A、B、START、SELECT。

> **注意**: 保存はカードの SRAM(LSDj と共有)の**最後の 8KB だけ**に書く(§1 の保存スロット)。LSDj のデータがあるスロットには書かない。ただし実機での確認は未なので、最初の保存の前後で SRAM をバックアップと比べる([CARTRIDGE.md](CARTRIDGE.md))。

## 1. 画面と移動
画面は一直線に並んでいる: **プレイ ⇄ PATCH(音色編集) ⇄ シーケンサー(ピアノロール) ⇄ キーボード**。端で止まる。

| 操作 | 動作 |
|---|---|
| START+→ / START+← | 次 / 前の画面(START を押したまま ←→ を続けて押せば何枚でも移れる)。START だけでは何もしない |
| SELECT を単押し | 次のチャンネル(CH1→CH2→CH3→CH4。PATCH 画面は、その次に MIDI ページ) |
| SELECT+START | シーケンサーの再生 / 停止(どの画面でも) |
| START+↓ | **スロット一覧画面**を開く(プレイ・PATCH・シーケンサーのどこからでも)。START+↑ で元の画面へ戻る |
| SELECT+←/→(プレイ画面) | 保存スロットを切り替え(1〜8) |
| SELECT+A | 現在のスロットへ保存 |
| SELECT+B | 現在のスロットから読み込み |

**保存スロット**: 音色・パターン・BPM・ループ長をひとまとめに、8 か所に保存できる。現在のスロットと、そこに保存があるか(`USED` / `FREE`)はプレイ画面の `SLOT n` の行に出る。
- **スロット一覧画面**(START+↓): 8 スロットを縦に並べ、`USED` / `FREE` と、選択中の `>` を一度に見られる。↑↓ で選び、**A で読み込み、B で保存**。この画面では START+←→ は効かない(START+↑ だけで戻る)。
- **曲の名前**(8 文字、使える文字は 空白・A-Z・0-9・`-`): スロット一覧画面の下の `NAME` の行で付ける。**←→ でカーソル(`+` の印)を動かし、SELECT+↑↓ でその位置の文字を変える**。名前は曲の一部として、保存すると一緒にスロットへ書かれ、読み込むと戻る。一覧には各スロットの名前が出る。名前を変えただけでは保存されないので、B で保存する。
- すでに保存があるスロットへ SELECT+A(一覧画面では B)を押すと、`AGAIN:OVERWRITE` と出る。**約 1.5 秒以内にもう一度**同じ操作をすると上書きする(間違えて消さないため)。
- スロットに LSDj のデータなど、ChromaSynth の保存でないものが入っていたら、書かずに `SLOT IN USE` と出る。
- 結果は画面の最下行に `SAVED n` / `LOADED n` / `NO SAVE DATA n` / `SAVE FAILED n` などと出る(n はスロット番号)。
- 起動時はスロット 1 に保存があれば自動で読み込む(最後に使ったスロットは覚えない)。**自動保存はしない**。

## 2. プレイ画面
- A: 選んだチャンネルを鳴らす(離すと止まる)。
- 十字キー: 鳴らす音の高さ(←→ = 半音、↑↓ = オクターブ)。
- 各チャンネルの発音中のノートと、MIDI で受けたバイトを表示。

## 3. PATCH 画面(音色編集)
チャンネルごとの音色を編集する。値の変更は**次のノートオンから**効く(PAN・VIBD/VIBS・全体の音量 VOLL/VOLR は即時)。

### 操作
| 操作 | 動作 |
|---|---|
| ↑ ↓ | パラメータの行を移動(使わない行は飛ばす。8 行ごとにページが変わり、右上に `P1`/`P2`/`P3`) |
| ← → | 値を ±1 |
| SELECT+↑ / SELECT+↓ | 値を ±10(範囲の端で止まる。この間はチャンネルが変わらない) |
| A | 試聴(選んだチャンネルを鳴らす) |
| B を押しながら十字キー | 試聴する音の高さを変える |
| SELECT 単押し | 次のチャンネル |

### パラメータ(略称の意味)
括弧内は値の範囲。**0 のときの意味**を書いてあるものは、0 が「効果なし」。

**全チャンネル共通に近いもの**

| 略称 | 正式名 | 意味 | 対象 |
|---|---|---|---|
| DUTY | デューティ比 | 矩形波の幅(0=12.5% / 1=25% / 2=50% / 3=75%)。音色の硬さが変わる (0-3) | CH1 CH2 |
| WAVE | 波形 | CH3 の波形(0=矩形 / 1=ノコギリ / 2=三角 / 3=サイン) (0-3) | CH3 |
| LVL | 出力レベル | CH3 の音量(0=100% / 1=50% / 2=25%)。エンベロープがないので音量はこれだけ (0-2) | CH3 |
| WDTH | LFSR 幅 | ノイズの幅。0=15 ビット(ざらざらした雑音)、1=7 ビット(金属的・ピッチのある音) (0-1) | CH4 |
| VOL | 初期音量 | 音の出だしの音量 (0-15) | CH1 CH2 CH4 |
| EDIR | エンベロープの向き | 0=下がる(減衰)、1=上がる (0-1) | CH1 CH2 CH4 |
| EPAC | エンベロープの速さ | 音量が 1 段変わるまでの時間(1 が速く 7 が遅い)。**0=変化なし**(VOL のまま鳴り続ける) (0-7) | CH1 CH2 CH4 |
| LEN | 音の長さ | **0=鍵盤を離すまで**。それ以外は APU が自動で止める(約 1/256 秒単位)。CH1/2/4 は 1-64、CH3 は 1-255 (0-64 / 0-255) | CH1-4 |
| PAN | パンニング | 0=左右両方、1=左のみ、2=右のみ (0-2) | CH1-4 |
| VIBD | ビブラートの深さ | **0=なし**。大きいほど深く揺れる。MIDI のモジュレーションホイール(CC1)でも上がる (0-7) | CH1-3 |
| VIBS | ビブラートの速さ | 揺れの速さ (0-7) | CH1-3 |

**CH1 だけのスイープ(2 ページ目)**: 音の途中で、ピッチを自動で上下に動かす APU の機能。

| 略称 | 意味 |
|---|---|
| SWT | スイープの間隔(時間)。**0=スイープなし**。大きいほどゆっくり (0-7) |
| SWD | 向き。0=ピッチが下がる、1=上がる(ハードの NR10 の向きに合わせてある。逆に聞こえたら入れ替えて確認する) (0-1) |
| SWS | 1 回の動く量(シフト)。大きいほど 1 回の変化が小さい (0-7) |

**CH4 だけ**

| 略称 | 意味 |
|---|---|
| NDIV | ノイズの分周比。小さいほど高く、大きいほど低い雑音(ハイハット→スネア→バスドラの方向)。WDTH と合わせて音程の高低を決める (0-7) |

### 3 ページ目(CH1-3: アルペジオ・スライド・デューティ切り替え) — M9b
すべてフレーム単位(1 フレーム ≒ 1/60 秒)。

| 略称 | 意味 |
|---|---|
| ARP1, ARP2 | **アルペジオ**。基音 → 基音+ARP1 半音 → 基音+ARP2 半音、の順に繰り返す。**両方 0 で無効**。音域を超える段は飛ばす。長三和音は ARP1=4、ARP2=7、短三和音は 3 と 7 (0-15) |
| ARPS | アルペジオの 1 段のフレーム数(0 は 1 と同じ)。大きいほどゆっくり (0-15) |
| SLID | **スライド(ポルタメント)**。前の音がまだ鳴っているときに次の音が来ると、音程が滑る。**0=なし**、1=速い〜7=遅い。シーケンサーで続けて置いた音符も滑る (0-7) |
| DUT2, DSPD | **デューティの切り替え**(CH1・CH2 のみ)。DUTY と DUT2 を DSPD フレームごとに交互に切り替える。**DSPD=0 で無効**。**LEN を使っている間は切り替わらない**(ハードの NRx1 に長さも入っていて、書き直すと長さが最初からになるため) (DUT2 0-3 / DSPD 0-15) |

### MIDI ページ(SELECT で CH4 の次)
| 略称 | 意味 |
|---|---|
| CH1〜CH4 | その GB チャンネルが聞く MIDI チャンネル(0=無効、1-16)。初期値は 1,2,3,4。同じ番号にすると和音になる |
| BEND | ピッチベンドの幅(半音)。初期値 2 (0-12) |
| VELO | 1=ベロシティで音量を変える、0=変えない |
| MODW | 1=モジュレーションホイール(CC1)でビブラートの深さを変える、0=変えない |
| SYNC | DAW 同期。0=OFF、1=OUT(本体がマスター)、2=IN(DAW に追従) |
| VOLL, VOLR | **全体の音量**(左 / 右)。0-7。ハードの NR50 |

## 4. シーケンサー画面(ピアノロール)
1 拍 = 12 ティック。画面の見方・設計の詳細は [ROLL_DESIGN.md](ROLL_DESIGN.md)。

| 操作 | 動作 |
|---|---|
| 十字キー | カーソルを 1 セル / 1 半音(押しっぱなしでリピート) |
| B を押しながら十字キー | 4 セル / 1 オクターブ動く |
| A | カーソルの位置に 1 セル分の音を置く(同時に試聴) |
| A を押しながら ← → | その音を 1 セル短く / 長く |
| A を押しながら ↑ ↓ | その音を移調 |
| B(タップ) | カーソルの位置の音を削除 |
| B+A(同時でも可) | グリッド分割を切り替え(1/4 → 1/4T → 1/8 → 1/8T → 1/16 → 1/16T → 1/48 → …。T は三連符) |
| SELECT を押しながら ↑ ↓ | BPM ±1 |
| SELECT を押しながら ← → | ループの長さ ∓1 小節(1〜4) |
| SELECT 単押し | チャンネル切り替え |
| SELECT+START | 再生 / 停止 |

シーケンサーは再生したまま、他の画面で音色を編集できる。三連符の入れ方: B+A で 1/8T にして、A → → A → → A(1 セルが 4 ティック)。

## 5. キーボード画面(MIDI 受信用)
Chromatic の内蔵 ESP32(BLE / USB)から、DAW の MIDI を受ける画面。この画面では本体のボタンを無視する(誤って鳴らさないため)。
- 抜けるには **START+←**(シーケンサーへ戻る)。
- SELECT 単押し = 次のチャンネル、SELECT+START = シーケンサーの再生 / 停止。
- 接続の手順は [BLE_MIDI.md](BLE_MIDI.md) の「現状」を読む。本体の MENU の System タブで MIDI MODE(OFF / BLE / USB)を選ぶ。
