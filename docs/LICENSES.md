# ライセンスと権利関係(公開のための整理、素案)

| 部分 | ライセンス | 備考 |
|---|---|---|
| ROM(`src/`、`inc/`)、生成スクリプトと試験(`tools/`)、Mac アプリ(`tools/mac/`)、外付けブリッジ(`firmware/`)、文書(`docs/`) | **MIT**(ルートの `LICENSE`) | 自作。`inc/hardware.inc` も自前の最小版(RGBDS 付属のものではない) |
| `chromatic-mcu/`(パッチと `src/`) | **GPL-3.0**(`chromatic-mcu/LICENSE.md`) | ModRetro の MCU ファームウェア(GPL-3.0)の派生物。元のソース・バイナリは含めない |
| LSDj | **含めない** | 作者個人のカートリッジに、別のページとして入っている。バックアップは、リポジトリに入れていない |
| ModRetro / Chromatic の名前 | 商標は、それぞれの権利者のもの | 「Chromatic 対応」と書くのみ。公認・提携ではない。ロゴは使わない |
| ビルドに使う道具(RGBDS、PyBoy、ESP-IDF、Xcode のコマンドラインツール) | それぞれのライセンス | 配布物には含めない |

## 公開前の確認(2026-11-10)
- **履歴の確認**: 141 コミット。API キー、パスワード、秘密鍵、`.env` は、どのコミットにも無し。300 KB を超える大きなファイルも無し。現在のファイルにも、ローカルのパスや個人の名前は無し。`.agents/` と `.claude/` は、作者の作業設定(許可するコマンドの一覧と、作業メモ)で、秘密は無し。
- **コミットのメールアドレス**: 99 コミットのメールは、作者の Gmail アドレス、12 コミットは GitHub の noreply アドレス。公開すると、前者は誰でも見られる。気になる場合は、履歴の書き換え(`git filter-repo` のメールの置き換え + 強制 push。PR のリンクは、番号は残るが、コミットの ID は変わる)が要る。しない選択もできる(多くの人は、そのまま)。
- **古いブランチ**: リモートに `feat/m9b-effects`、`fix/duty-with-length` が残っている(マージ済みか、確認して消す)。

## 決めること(作者)
1. ルートのライセンス: **MIT**(素案)か **Apache-2.0**(特許条項つき)。ROM は、特許を気にする必要はあまりないので、MIT で十分と考える。
2. コミットのメールアドレスを、書き換えるか。
3. `chromatic-mcu/` の GPL-3.0 の全文を、そのディレクトリに置く(配布の前)。
