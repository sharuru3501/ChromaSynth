# 対応するカートリッジ(普通の GB / GBC カートリッジに書く場合)

ChromaSynth の ROM は **32 KB**(`build/chromasynth.gb`)で、**MBC5 + 電池バックアップ SRAM 32 KB** のカートリッジ向けです。曲の保存(SRAM)以外は、特別なハードに依存しません。

## 必要なもの
| 項目 | 内容 |
|---|---|
| ROM | 32 KB(バンクの切り替えなし。ROM バンク 0 と 1 だけ) |
| マッパー | **MBC5**(ヘッダのカートリッジ種別 `$1B` = MBC5+RAM+BATTERY) |
| SRAM | **32 KB**(8 KB × 4 バンク)、電池つき。曲を保存しないなら無くても動く(SELECT+B は `SAVE FAILED` と出る) |
| 本体 | GBC / GB(DMG)。ROM は CGB 対応(`$80`)で、DMG でも起動する作り。動作を確認したのは **ModRetro Chromatic(GBC 相当)と、エミュレータ(SameBoy、PyBoy)だけ** |

## ビルドと書き込み
```bash
make            # build/chromasynth.gb: 32 KB ROM、SRAM 32 KB、保存スロットは SRAM のバンク 0〜3
```
- 出来た `.gb` を、お使いのカートリッジライター / フラッシュカートで書いてください。書き方はそれぞれの道具の説明書に従います。
- ヘッダ: タイトル `CHROMASYNTH`、MBC5+RAM+BATTERY、ROM 32 KB、RAM 32 KB(`rgbfix -r 3`)。**書き込みの前に、カートリッジのマッパーと SRAM の大きさが合っているか確かめてください。**
- **SRAM に、ほかのソフトのセーブデータが入っているカートリッジに書かないでください。** ChromaSynth は SRAM の 4 つのバンクを使います(下)。

## 曲の保存(SRAM の使い方)
- 保存スロットは **4 つ**。1 つが 8 KB(バンク 1 つ)で、スロット n(0〜3)は SRAM のバンク n。
- 保存するのは、**SELECT+B**(読み込みは SELECT+A)。**自動保存はしません。** 空のスロット(全部 `$00` か `$FF`)と、ChromaSynth の保存だけを書き換えます。ほかのデータが入っているスロットは、書かずに `SLOT IN USE` と出します。
- 形式は `src/sram.asm` の冒頭に書いてあります(`CSYN` + 版番号 + 音色 + 曲 + 名前 + 拍子・波形)。形式を変えたら版番号を上げ、古い保存は読み込みません。
- 電池が切れると、保存が消えます。カートリッジの電池は消耗品です。

## ほかのカートリッジの場合(未確認)
- **MBC3 や MBC1**: SRAM の切り替えの書き方が違うので、そのままでは保存できない可能性が高いです。確認していません。
- **SRAM が 8 KB だけ**のカートリッジ: スロット 2〜4 が使えません。確認していません。
- **フラッシュカートで SRAM の割り当てが特殊**なもの(LSDj 用の 128 KB のカードなど): 下の「作者の環境」を参照。

## 作者の環境(EMS 64M スマートカード)
作者は、LSDj を入れたスマートカードのページ 2 に書いて使っています。そのカードは SRAM(128 KB)を LSDj と共有していて、LSDj が SRAM のバンク 0〜11 を使うので、保存スロットをバンク 12〜15 に置いた別ビルドを作っています。

```bash
make card       # build-card/chromasynth.gb: SRAM 128 KB、保存スロットは SRAM のバンク 12〜15
```
詳しい書き込みの記録と手順は [CARTRIDGE.md](CARTRIDGE.md)(作者の個人的な記録です)。**普通のカートリッジ用の `make`(既定)の ROM を、LSDj が入ったカードに書かないでください**(保存が LSDj の領域に当たります)。
