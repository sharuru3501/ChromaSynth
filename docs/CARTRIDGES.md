# 対応するカートリッジ(普通の GB / GBC カートリッジに書く場合)

ChromaSynth の ROM は **32 KB** で、**ゲームボーイカラー(GBC)以降**用です。カートリッジの SRAM(電池バックアップ)の大きさで、**2 つの版**があります。

| 版 | 作り方 | SRAM | 保存できる曲 | 対象 |
|---|---|---|---|---|
| **通常版(32 KB)** | `make` → `build/chromasynth.gb` | 32 KB | **4 曲** | SRAM 32 KB(以上)のカートリッジ |
| **機能制限版(8 KB)** | `make small` → `build-8k/chromasynth.gb` | 8 KB | **1 曲** | SRAM 8 KB のカートリッジ(市販ソフトにも多い) |

- **音を作る・打ち込む・演奏する機能は、どちらも同じ**です。違うのは**保存できる曲の数だけ**。
- ROM は、**自分のヘッダに書いてある RAM の大きさ**を見て、スロット数を決めます(32 KB 以上 = 4、8 KB = 1、SRAM なし・2 KB = 保存なし。保存しようとすると `SAVE FAILED`)。
- **カートリッジに合った版を書いてください。** 8 KB のカートリッジに通常版を書くと、バンクを切り替えても同じ 8 KB が見える作りの場合、スロット 2〜4 への保存がスロット 1 を上書きする恐れがあります(ROM は実際の SRAM の大きさを確かめられません)。
- 対象は **8 KB と 32 KB** です。それ以外の大きさ(2 KB、64 KB、128 KB など)は想定していません。128 KB 以上は 32 KB 版として動きます(4 曲)。

## 必要なもの
| 項目 | 内容 |
|---|---|
| ROM | 32 KB(バンクの切り替えなし。ROM バンク 0 と 1 だけ) |
| マッパー | **MBC5 を推奨**(ヘッダのカートリッジ種別 `$1B` = MBC5+RAM+BATTERY)。MBC3 と MBC1 でも保存できるように作ってある(PyBoy で確認。**実機は未確認**)。下の「MBC について」 |
| SRAM | 電池つき。32 KB(通常版)か 8 KB(機能制限版)。保存しないなら無くても動く |
| 本体 | **ゲームボーイカラー(GBC)以降が必要**(Chromatic は GBC 相当)。パターンのデータを GBC の切り替え式ワーク RAM(バンク 1〜4)に置くので、バンクのない DMG(初代 GB など)では動きません。ヘッダは CGB 専用(`$C0`)で、DMG では起動しません。動作を確認したのは **ModRetro Chromatic と、エミュレータ(SameBoy、PyBoy)だけ** |

## MBC について
- MBC(Memory Bank Controller)は、カートリッジの中のチップで、ゲームボーイの小さな窓(ROM 32 KB、SRAM 8 KB)の中身を切り替えます。
- ChromaSynth の ROM は 32 KB なので、**ROM の切り替えは要りません**。MBC が関わるのは **SRAM のバンク切り替え**(曲スロットの切り替え)だけです。
- **おすすめは MBC5**(GBC 時代のカートリッジや、いまのフラッシュカート、自作カートで最も一般的)。ヘッダも MBC5 で作ります。
- MBC3(時計つき)は、SRAM の有効化とバンクの選び方が MBC5 と同じで、MBC1 は RAM バンキングモードの選択が要ります。ROM は SRAM を開くたびに `$6000` へ 1 を書いて両方に対応させています(MBC5 では何も起きず、MBC3 では時計のラッチにならない)。PyBoy(MBC1 / MBC3 / MBC5 のエミュレーション)で、スロット 4 の保存と読み込みを確認しています。**実機は確認していません。**
- MBC なし(ROM ONLY)のカートリッジ: 保存はできませんが、演奏はできます。

## ビルドと書き込み
```bash
make            # 通常版: build/chromasynth.gb(32 KB ROM、SRAM 32 KB、保存スロットは SRAM のバンク 0〜3)
make small      # 機能制限版: build-8k/chromasynth.gb(SRAM 8 KB、保存は 1 曲)
```
- 出来た `.gb` を、お使いのカートリッジライター / フラッシュカートで書いてください。書き方はそれぞれの道具の説明書に従います。
- ヘッダ: タイトル `CHROMASYNTH`、CGB 専用、MBC5+RAM+BATTERY、ROM 32 KB、RAM は版に応じて 32 KB(`rgbfix -r 3`)か 8 KB(`-r 2`)。**書き込みの前に、カートリッジのマッパーと SRAM の大きさが合っているか確かめてください。**
- **SRAM に、ほかのソフトのセーブデータが入っているカートリッジに書かないでください。** ChromaSynth は SRAM のバンク 0 から(通常版は 4 つ、機能制限版は 1 つ)を使います。

## ワーク RAM(WRAM)について
WRAM は本体の中にあり、カートリッジには無いので、どのカートリッジでも同じです(GBC は 32 KB: 8 KB × 4 ではなく、固定 4 KB + 切り替え式 4 KB × 7 バンク)。ChromaSynth はバンク 1〜4 を使います。カートリッジ側で違うのは **ROM の大きさ、マッパー、SRAM の大きさ**だけです。
ROM は 32 KB で ROM バンクを切り替えないので、マッパーが関わるのは **SRAM のバンク切り替え**(曲の保存)だけです。

## 曲の保存(SRAM の使い方)
- 保存スロットは、通常版が **4 つ**、機能制限版が **1 つ**。1 つが 8 KB(バンク 1 つ)で、スロット n は SRAM のバンク n。
- 保存するのは、**SELECT+B**(読み込みは SELECT+A)。**自動保存はしません。** 空のスロット(全部 `$00` か `$FF`)と、ChromaSynth の保存だけを書き換えます。ほかのデータが入っているスロットは、書かずに `SLOT IN USE` と出します。
- 形式は `src/sram.asm` の冒頭に書いてあります(`CSYN` + 版番号 + 音色 + 曲 + 名前 + 拍子・波形)。形式を変えたら版番号を上げ、古い保存は読み込みません。
- 電池が切れると、保存が消えます。カートリッジの電池は消耗品です。

## ほかのカートリッジの場合(未確認)
- **MBC3 や MBC1**: 保存できるように作ってありますが、実機では確認していません(上の「MBC について」)。
- **SRAM が 8 KB だけのカートリッジに通常版を書くこと**: 上のとおり、上書きの恐れがあります。**機能制限版を使ってください。**
- **フラッシュカートで SRAM の割り当てが特殊**なもの(LSDj 用の 128 KB のカードなど): 下の「作者の環境」を参照。

## 作者の環境(EMS 64M スマートカード)
作者は、LSDj を入れたスマートカードのページ 2 に書いて使っています。そのカードは SRAM(128 KB)を LSDj と共有していて、LSDj が SRAM のバンク 0〜11 を使うので、保存スロットをバンク 12〜15 に置いた別ビルドを作っています。

```bash
make card       # build-card/chromasynth.gb: SRAM 128 KB、保存スロットは SRAM のバンク 12〜15
```
詳しい書き込みの記録と手順は [CARTRIDGE.md](CARTRIDGE.md)(作者の個人的な記録です)。**普通のカートリッジ用の `make`(既定)の ROM を、LSDj が入ったカードに書かないでください**(保存が LSDj の領域に当たります)。
