# MIDI 入力(M3)

ROM は「リンクポートに届いた MIDI バイト列」だけを扱う(トランスポート非依存)。
有線(USB-MIDI → マイコン → リンクケーブル)と BLE MIDI(ESP32 ブリッジ)は、どちらもブリッジ側の仕事。ブリッジ側のファームは未実装(M6/M8)。
エミュレータにはリンク入力が無いので、テストは `wRing`(シリアル受信リングバッファ)へバイトを直接積んで行う。

## 設定(音色編集画面の5ページ目)
`START` で音色編集画面 → `SELECT` を CH4 の次まで進める(`CH5 MIDI`)。保存データ(SELECT+A)にも含まれる。

| 行 | 内容 | 範囲 | 既定 |
|----|------|------|------|
| CH1〜CH4 | その GB チャンネルが聞く **MIDI チャンネル**(0 = 無効) | 0〜16 | 1, 2, 3, 4 |
| BEND | ピッチベンド幅(半音) | 0〜12 | 2 |
| VELO | ベロシティで音量を変える | 0/1 | 1 |
| MODW | CC1(モジュレーションホイール)でビブラート深さを変える | 0/1 | 1 |

## ポリフォニック
**複数の GB チャンネルを同じ MIDI チャンネルに割り当てる**と、そのチャンネル群で和音になる。
例: CH1 と CH2 を両方「1」にすると、MIDI ch1 で 2 音の和音(パルス2声)。CH3(波形)も足せば3声。
新しい音の行き先は、(1) 同じ音が鳴っているチャンネル(再打鍵)、(2) 空いているチャンネル、(3) 全部ふさがっていれば**持ち回りで1つ奪う**、の順。
音域外の音(波形は MIDI 36〜95)はそのチャンネルでは鳴らない。

## 対応メッセージ
| メッセージ | 動作 |
|------------|------|
| ノートオン / ノートオフ | 割り当てに従って発音/消音。ベロシティ0のノートオン = ノートオフ。ランニングステータス対応 |
| ベロシティ | パルス/ノイズ: 音量 = 音色の音量 × (ベロシティ/8 + 1) / 16(最小1)。波形: ベロシティが小さいほど出力レベルを1〜2段下げる |
| CC1 | ビブラート深さ = 値 / 16(0〜7)。音色の深さより小さくならない |
| CC120 / CC123 | その MIDI チャンネルを聞いている GB チャンネルを全て消音 |
| ピッチベンド | MSB のみ(64 = 中央)。幅は BEND 設定。**指数曲線の表**(`tools/gen_bend.py`)で周期の増減を求めるので、12 半音でもちょうど 1 オクターブ |
| 無視 | プログラムチェンジ、アフタータッチ、その他の CC、リアルタイム(クロック/スタート/ストップ。DAW 同期は M6) |

ベンドとビブラートは足し合わされる。新しく鳴らす音は、保持中のベンドを最初から反映して鳴る。

## 実装メモ
- ルーティング: `src/midi.asm`(`MidiNoteOn` の3パス: 再打鍵 → 空き → 持ち回りで奪う)。
- 発音: `NoteOn`(a=ノート, c=チャンネル)は MIDI 非依存。ベロシティは `wNoteVel` 経由で渡す(MIDI 以外の発音は常に 127)。
- 毎フレームの変調(`TickChannel`): ビブラート + ベンドを符号付き16bitで合成し、`wBase`(素の周期)に足してレジスタへ書く。変調が0に戻った時は素の周期を1回だけ書き戻す。
- ベンド量: `s = m/16` 半音(m = |bend| × 幅 / 4)。`offset = (P>>3) × factor(m) / 16`(P = 2048 − 周期、factor は ×128 のスケール)。割り算なし、掛け算2回と表引き1回。
- テスト: `tools/headless_midi_test.py`。
