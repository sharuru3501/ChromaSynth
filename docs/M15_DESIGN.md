# M15 DAW との MIDI 同期と録音 — 設計(2026-11-10)

目標の順(ユーザーの優先): **(1) Chromatic のシーケンサーを DAW に録音(MIDI From)**、あとで (2) 遅れの測定と補正、(3) DAW のスタート/停止・テンポに追従、(4) プログラムチェンジでパターン切り替え・CC で音色。この文書は (1) の設計。

## 1. 何ができるか
ChromaSynth のシーケンサーが鳴らす音(4 チャンネル)・クロック・スタート/停止を、Chromatic → ESP32 → Mac のアプリ → DAW の MIDI 入力 `ChromaSynth` に流す。DAW(Live)で、この入力を録音すれば、Chromatic のシーケンサーの演奏が MIDI クリップになる。クロックを Live の外部同期に使えば、Chromatic がマスターになる。

```
ROM(SYNC = OUT)──wTx──▶ 上りスロット(OBJ パレット 1)──gpd──▶ ESP32 ──BLE 通知 / USB の `u ..` 行──▶ ChromaSynth Link ──▶ MIDI 入力「ChromaSynth」──▶ DAW
```

## 2. ROM 側(すでにある)
- MIDI ページの **SYNC = 1(OUT)**: シーケンサーが、1 ティックごとにクロック `$F8`(1 拍 12 回)、再生・停止で `$FA` / `$FC`、チャンネルのノートオン・オフ(MIDI チャンネルは MIDI ページの CH1〜CH4)を `wTx` に積む。
- リンクが確立している間(ROM が**キーボード画面**にいる間)、`CLinkUp` が 1 フレームに 1 メッセージ(最大 3 バイト)を上りスロットに書く(連番 `seq` 0〜7 が進む)。
- 制約: **キーボード画面にいる間だけ**(リンクはそこでしか張らない)。録音中はキーボード画面にしておく。SELECT+START(再生・停止)はどの画面でも使える。
- 帯域: 1 フレーム 1 メッセージ = 最大 60 メッセージ/秒。クロックは BPM × 12 / 60 回/秒(120 BPM で 24、200 BPM で 40)で、残りがノート用。BPM が高い曲では、ノートが多いとあふれる(`wTx` は 256 バイトで、あふれたら捨てる)。

## 3. ESP32 側(v19)
- `chl_up_decode`(`chlink_proto.c`、ホストでテスト): スロットの `seq` が進んだら、新しいメッセージ(長さ 1〜3)を返す。ビーコン($F4・$F5)と空のスロットは返さない。最初に見たスロットは覚えるだけ(古いかもしれない)。
- リンクのタスクは、**スロットを読むたびに**(状態の確認、ack の確認、見張りの前)`up_feed` でメッセージを探す。アップリンクが ON で、リンクが武装しているときは、スロットを待ち時間なしで読み続ける(1 回約 7 ms。ROM は 1 フレーム 1 メッセージ)。
- **BLE**: Mac が MIDI 特性の通知を購読したら ON(切れたら OFF)。メッセージごとに、BLE MIDI のパケット(ヘッダ、時刻、メッセージ)を通知する。時刻は ESP32 がスロットを読んだ時刻(ミリ秒の 13 ビット)。
- **USB**: コンソールの `up on` で ON。メッセージは `u 90 3c 64` の行で出る。モードが変わるとき、アップリンクは OFF から始まる(`up on` は何度言っても同じ)。
- `link stat` に、アップリンクの ON/OFF と受け取ったメッセージ数。

## 4. Mac アプリ(ChromaSynth Link)
- CoreMIDI の**仮想入力 `ChromaSynth`**(DAW の MIDI From / 入力)を作る。
- BLE: 特性の通知を購読して、パケットを解析(`parseBLEMIDI`)。USB: 行 `u ..` を読む(`uplinkMessage`)。
- **クロックを倍にする**: ROM は 1 拍 12 回、DAW は 24 回を期待する。`$F8` ごとに、直前の間隔の半分あとに、もう 1 つ `$F8` を足す(`ClockDoubler`。スタート/停止で間隔を忘れる)。

## 5. 使い方(Live)
1. ChromaSynth の MIDI ページで **SYNC = OUT**(1)。ROM を**キーボード画面**にする。
2. ChromaSynth Link を動かす(BLE か USB でつながっている)。
3. Live の環境設定 > Tempo & MIDI: 入力ポートの `ChromaSynth` の **Track** を入れる(クロックで同期するなら **Sync** も)。
4. MIDI トラックの入力を `ChromaSynth`、録音待機にして、録音を始める。
5. Chromatic で SELECT+START(シーケンサーの再生)。ノートが Live に録音される。

## 6. 試験
- ホスト: `make check-mcu`(`chl_up_decode`)、`tools/mac/test.sh --selftest`(BLE MIDI の解析、行の解析、クロックの倍化)。
- 実機: ESP32 v19 を書き込んでから、上の手順で、ノートの数と順序、クロックの間隔(120 BPM で DAW が 120 と表示)、スタート/停止が DAW に届くことを確認。**未確認**。

## 7. 後回し(次のステップ)
- 遅れの測定と補正(録音した音声の遅れ。音声ケーブルがあると正確)。
- DAW のスタート/停止とテンポへの追従(下りは約 15 B/s なので、24 回/拍のクロックは送れない。スタート/停止と BPM だけを送る)。
- プログラムチェンジ(パターン切り替え)と CC(音色)。
- キーボード画面以外からも送る(ROM の画面と、リンクの張り方の見直しが要る)。
